## Software citation template

Use only after author approval and creation of the corresponding release:

```text
[APPROVED SOFTWARE AUTHORS]. [APPROVED SOFTWARE TITLE]. Version [FINAL VERSION].
[ARCHIVE / PUBLISHER], [RELEASE YEAR]. [VERSION-SPECIFIC DOI OR PERSISTENT URL].
```

Software contributors may differ from manuscript authors. Do not infer attribution from account names, paths or Git configuration. Cite the exact version used in the manuscript; if both a version DOI and all-versions identifier exist, identify the specific release.
